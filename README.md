# Trumark

From this folder, run `npm ci`, then `npm run dev`. Open http://localhost:3000.

For a local production preview, run `npm run build`, then `npm run serve`. Open http://127.0.0.1:4173.

On Vercel, import the project and select the folder containing package.json as the root directory. Use the Next.js framework preset and the npm run build command.

To keep future copies small, exclude node_modules, .next, and out after local development.
